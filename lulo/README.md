# Lulo Café Bar · sitio web

React + Vite + Tailwind. Sin backend.

    npm install
    npm start        # desarrollo
    npm run build    # producción (carpeta build/)

- Textos ES/EN: `src/i18n/translations.js`
- Teléfono, Instagram, enlaces, imágenes: `src/data/content.js`
- Loading de neón: `src/loader/NeonLoader.jsx` (`DURATION` = duración en ms)
