# Tres Raíces · sitio web

React + Vite + Tailwind.

    npm install
    npm start        # desarrollo (igual que npm run dev)
    npm run build    # producción (carpeta build/)
    npm run preview  # ver la carpeta build/ en local

Todo el contenido (textos, WhatsApp, correo, imágenes) se edita en `src/data/content.js`.
Cada sección es un archivo en `src/sections/`.
